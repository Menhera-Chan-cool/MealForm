## Implemented behavior

- Table layout memory stores only a version, non-content schema fingerprint, column count, numeric optional hidden indexes and bounded committed widths. Three explicit table namespaces, at most eight schemas each; no names, header text, row content, credentials or delete tokens. Calendar dates are stripped only for schema matching; changed serving-day/projection structure is isolated. Required columns cannot be hidden, mobile restores all fields, and denied/corrupt storage leaves transient controls usable. Pointer cancel never writes; keyboard resizing is ignored during a live pointer drag so Escape cancels the whole drag. Existing size-only reset remains; ColumnChooser adds full layout reset. Preferences are shared on this browser/device, not account/cloud synchronization.
- Quick View uses actual responseId neighbors from the currently loaded filtered/sorted list. It does not fetch more pages or offer mutation actions. Counter labels the loaded subset. Duplicate names remain separate; ambiguous/missing current IDs disable navigation rather than guessing. The original native dialog, verified/cache disclaimer, actual serving-day labels and close-focus behavior remain. Selected names and position are announced politely. Mobile navigation stacks to avoid squeezing the disabled action beside its help trigger.
- Logo input feedback reuses the existing preview image's events, with original no-referrer policy. Current URL/attempt identity guards ignore stale completion. Blank is optional; syntax errors are distinct from a browser image-load failure and do not falsely prove a remote file is absent/private. Explicit retry remounts the same URL without adding query parameters. Feedback never edits the URL, auto-saves, bypasses server validation or blocks a valid URL solely because of network availability.
- Audit date groups use Vietnam dates, original event objects/order, the current filtered loaded slice and a visible count of pending/review/failed/partial events. Unknown timestamps are explicit and not shown as a fake 1970 date. Collapsing retains the group's issue indicator; changed week/filter resets folding. One table retains original row actions and column controls; a shared context-aware full-span cell follows actual visible PC columns and complete mobile columns, avoiding ghost columns after hiding fields.
- Archive status filtering treats only explicit `open`/`closed` as known; missing/invalid metadata is Unknown. It intersects month, supports List/Calendar, independent criterion clearing and allowlisted status preservation in week/back/breadcrumb links. No extra Form requests, fake zero counts or permission changes.
