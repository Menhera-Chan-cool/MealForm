- Summary meal names are native accessible buttons, using exact actual day/meal selection, not inferred weekday positions. Existing name and sort stay. Mobile switches to Details and focus moves to its heading/result count; Return restores previous filters, summary position and trigger focus. Zero matches keep Return available. Ordinary filter edits or a replaced dataset end drilldown. Exact meal matching is a local optional model argument only for drilldown; ordinary substring search remains unchanged. Existing preview callers can remain non-interactive without the callback.
- TableScroll wraps the existing viewport in viewer/submissions/history, preserving refs on the actual scrolling div, its contents, table widths, expansion and mobile cards. ResizeObserver/passive scroll derive left/right remaining-space flags with one-pixel tolerance. Noninteractive pseudo-elements render only edge shadows: no hint text, arrows, new focus targets or action interception. Observers/listeners detach on replacement/unmount.
- OCR issue links derive only from the incumbent inspectMenu result. Concrete date/meal IDs, full-week and serving-day targets let users focus the actual field; a reviewed warning day is explicitly reopened first. No text correction, allowMissing change, OCR rerun or Form creation is caused by navigation. Corrections and Undo still invalidate reviewed stamps and update the same existing validation.
- ExplainedButton renders the original native disabled condition and callback unchanged, with manual incumbent FieldHelp only while disabled. Keyboard and touch access do not enable or submit the action. Reasons cover missing image/week, pending reads/writes, invalid/existing menu, unverified cached responses, Form state, empty/conflicted notice and current system operations. Unauthorized tools remain hidden; no client-side inference of missing Google scopes. Original confirmations/optimistic revisions/deletion identities remain intact. Bounded zoom/required-column/review-checkbox controls retain their already explicit adjacent state text.
