## Implementation
- Random 256-bit sid in existing signed HttpOnly/SameSite=Lax/Secure cookie. Same sid on renewal; legacy cookie needs one new Google login, never auto-upgraded. Registry in execution-owner Apps Script User Properties: account hash, session hash, coarse browser/platform label and timestamps; no raw sid/token/Google proof/email/IP/location/raw UA. Maximum eight active records/account, no silent eviction; expired-only cleanup of the session namespace.
- Signed session register/check/renew/list/revoke and private GAS doPost enforcement. All protected Vercel gateways require live GAS acknowledgement; old immutable web deployments cannot bypass the GAS guard with old stateless cookies. Public current/next/branding unchanged. Store failures fail closed; no automatic retry of session mutations. Revocation applies to subsequently verified requests, not already accepted backend tasks.
- On-demand scoped session list, safe confirmation, exact-target receipts, unknown outcomes readonly until explicit refresh. Current-session logout reuses the Dashboard dirty/discard/draft-flush guard; cancel sends no revoke. Dialog measures the usable viewport when opened, keeps Close visible and restores focus.
- Separate static Viewer/Dashboard manifests and genuine 192/512 PNG icons rendered from the existing MealForm mark. Real install prompt only after user click, manual browser instructions otherwise, no fake installed/offline state. Notification-only worker: no fetch/cache/queue/sync/push handler.
- Account-scoped preference only in bounded local storage; generic OCR completion only after successful validated full/multi-image/region OCR, explicit opt-in and hidden tab. Stale account callbacks cannot deliver. Existing minute response-ID check drives window-scoped unread dot; no new poll or fabricated count. Successful explicit visible same-week refresh / viewing OCR acknowledges the matching reason; unsupported or rejected platform APIs retain in-page status.

## Limits and rollback
No physical phone install/OS badge/notification/screen-reader certification, no genuine Google sign-in or actual existing session revoked in QA. Platform support and presentation vary; window-scoped badge is not a global unread total. The existing Apps Script property/service quota and availability limit session storage; an unknown registration outcome can leave a record until explicit revocation or expiry. No offline/private cache or draft sync, no closed-web notification guarantee. Do not roll back only the web to a sid-less build while keeping strict GAS; use a tested compatible fix, or coordinate both sides knowingly.
