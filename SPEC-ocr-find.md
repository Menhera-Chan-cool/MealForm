# ocr-find
Find in current title/date/visible serving-meal text with accent-folded matching, count and Previous/Next/Enter navigation. Stable actual field IDs preserve weekday identity and duplicates; skip non-rendered closed-day meal inputs. Mark matching fields without overwriting validation/focus states, use existing jumpToReview to reopen reviewed days. Typing never steals focus; Enter in search never submits the creation form. Editing/Undo re-resolves matches; clear affects only search, new OCR/reset clears query. No replacement, extra OCR call or content mutation. Shared policy: CAPABILITY-MAP-ocr-navigation.md.
