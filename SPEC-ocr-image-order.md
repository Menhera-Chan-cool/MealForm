# ocr-image-order
Show indexed sources with a native drag handle and keyboard/touch Up/Down buttons. Move by exact array position, preserve entry objects, active preview/filename and budget; persist order through existing draft storage. Invalid, foreign, stale or cancelled drags do nothing. Disable ordering during work/loading or while OCR/menu/merge/region/Undo results are retained; explain replacing sources starts a new draft. No implicit OCR, deletion or source-pixel edit. Explicit next OCR submits sources in the shown order. Shared commands/style/verification/boundaries: CAPABILITY-MAP-ocr-navigation.md.
