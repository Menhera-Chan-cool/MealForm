## Limits / rollback

Paste is tab-delimited copied text, not file import or arbitrary HTML/CSV/formulas; dates require explicit calendar text, serial Excel dates are not guessed. Partial/bad menus remain drafts and never bypass existing creation validation. Offline mode only preserves already loaded/authorized content; no new offline cache, offline login, service worker, synchronization or mutation queue. Browser onLine=true does not prove server reachability. Feedback disappears on reload/logout and is not a durable audit log; raw errors use a generic safe entry. Physical devices/virtual keyboards, screen-reader speech, non-Chromium and cloud Chromatic are not certified. Existing nonfatal Lucide/chunk-size/color warnings remain. RAR/release-folder source is not rebuilt.
